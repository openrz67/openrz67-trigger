# PCB archive

Frozen fabrication packages: exactly what was uploaded to the fab, one folder per order.
Nothing here is the source of truth and nothing here changes after the order; the live
design is the KiCad project in [`../kicad/`](../kicad/). Whether a revision turned out to
work is a status line in its section below, not a separate folder.

## `2026-09-07-rev2/`

**Status: ordered from JLCPCB 2026-09-07, not yet received or tested.**

The fabrication package for **rev 2** (PhotoMOS relays, side-entry `U4`, BQ25185 +
TPS63031 power path, `J1` header), generated by `../kicad/tools/regen.sh` at commit
`0e1376e`. The boards do *not* have the pin-1 silk dots (`24bc07f`) or the routing
review fixes (`64ef2b8`, `4550987`: C23 at U2 VIN, opened GND necks, GPIO21 on one
layer, U3 EP vias) that are in `../kicad/` now; those go on the next order.

| File | What |
|---|---|
| `openrz67-gerber.zip` | Gerber and drill files, downloaded back from the JLCPCB order (identical to `0e1376e` apart from the header timestamp) |
| `openrz67-bom.csv` | BOM, downloaded back from the order; identical to `0e1376e` |
| `openrz67-pos.csv` | CPL, downloaded back from the order; identical to `0e1376e` |
| `openrz67-schematic.pdf` | schematic at that commit |
| `openrz67-top.png`, `openrz67-bottom.png` | renders |
| `drc.rpt`, `erc.rpt` | KiCad DRC/ERC at that commit (clean) |

## `2025-09-23-rev1/`

**Status: fabricated, assembled and working.** Its LGS5500 charger/boost was the reason
for the rev 2 power-path change.

The fabrication package for **rev 1**, exported from EasyEDA Pro on 2025-09-23. The enclosure in
[`../../case/`](../../case/) was first drawn against it; since 2026-09-05 it follows rev 2.

| File | What |
|---|---|
| `Gerber_…zip` | Gerber and drill files as ordered, including the board outline (`.GKO`) and `Drill_PTH_Through.DRL` |
| `BOM_…csv` | bill of materials as ordered |
| `PickAndPlace_…csv` | component placement as ordered; the source for the case's component positions |
| `3D_…step` | assembled board as STEP |
| `3D_…png` | render |

## `easyeda/`

The EasyEDA Pro project the KiCad port was made from, kept so the port stays
reversible.

| File | What |
|---|---|
| `ProPrj_…epro` | EasyEDA Pro **v2** export. This is the one that imports into KiCad; use it if the port ever has to be redone. |
| `ProPrj_…epro2` | EasyEDA Pro **v3** export. KiCad 10.0.6 imports this as an empty board, so it is kept for EasyEDA's own use only. |

The filenames carry spaces because they are the exports as EasyEDA produced them.
They are left unrenamed so they can be matched against the cloud project.
